Sound Chunk Marker — Minecraft 1.21.8 / Fabric

Что делает:
- Рисует красную рамку вокруг чанка, в котором клиент услышал подходящий звук.
- Отмечает взмахи/удары игрока (звуки entity.player.attack.*).
- Отмечает звуки сущностей entity.* — включая звуки смерти мобов.
- Игнорирует летучих мышей и зомби (включая drowned, husk и zombified piglin).
- Метка исчезает через 30 секунд.

Сборка:
1. Установи Java 21 JDK.
2. Распакуй архив.
3. Открой терминал в папке проекта.
4. Выполни: gradle build
5. Готовый JAR будет в build/libs/.

Установка:
Скопируй soundchunkmarker-1.0.0.jar из build/libs/ в .minecraft/mods.
Нужны Fabric Loader 1.21.8 и Fabric API для 1.21.8.

Важно:
Это клиентский мод. Он отмечает только звуки, которые Minecraft-клиент действительно получил/проиграл.
Дальность зависит от того, какие звуки сервер отправил клиенту и от настроек игры.
